Reset password

Generates a single-use temporary password and invalidates all current sessions. The temp password is shown once on this page; share it with the user out-of-band. The user will be forced to set a new password on next login (the temp credential cannot be reused).

MFA credentials

Removes the user's TOTP and every WebAuthn key. They will be prompted to re-enroll on next login if MFA is required by policy.

AWS sessions

Adds this user's UUID to every AWS federation role's AuthRevokedUsers inline policy, killing their current STS sessions within ~30s. The user can re-authenticate to auth and federate again immediately — this action does NOT deactivate the account. Use for lost-laptop / suspect-credential scenarios; use Delete user below for full lockout.

Compromised account reset

The "assume the worst" action when credentials may have leaked. In one click:

  • Issues a single-use temporary password and forces rotation on next login
  • Deletes TOTP and every WebAuthn credential (user must re-enroll MFA)
  • Kills all auth sessions and broadcasts back-channel logout to every RP
  • Revokes active AWS STS sessions via the federation revocation provisioner

The account remains Active. The user proves identity again via the temp password, sets a new permanent password, re-enrolls MFA, and re-federates AWS — all forced flows. Use Delete user below for full account lockoff.
