Compromised account reset

Use this coordinated response when credentials may have leaked. It:

  • Issues a single-use temporary password and forces rotation
  • Deletes TOTP and every WebAuthn credential
  • Ends all Auth sessions and broadcasts back-channel logout
  • Revokes active AWS STS sessions

The account remains active so the user can prove identity again, replace the password, and re-enroll MFA.
